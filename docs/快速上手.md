# Ring Dock 快速上手

1. 下载 `ring-dock-v...-windows-x64.zip` 并解压。
2. 双击 `ring-dock.exe` 启动；应用图标已经内嵌在 exe 中。
3. 点击圆环上的分类展开，再将应用或文件快捷方式拖到面板里。
4. 右键圆环打开设置，可改分类图标、圆环显示方式、面板图标样式和布局。

收藏只记录原路径，不搬动原文件。设置文件 `config.json` 与 exe 放在一起。退出程序后，删除程序目录即可卸载；是否保留 config.json 由你决定。

如果检测到可选的 WinMemoryCleaner，首次启动时会请求一次 UAC 权限来启动内存整理助手。未安装该组件或拒绝授权时，圆环仍可运行。
