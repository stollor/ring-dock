# Ring Dock 内存占用测量

## 测试条件

- 测试环境：Windows 11，工作区 2560×1392。
- 使用同一份配置，依次打开全部四个分类并收起；报告中的数据在两轮或三轮操作后采样。
- 预览版对比使用本次优化前后的程序；正式版数据来自优化后的 release 实例。
- 关闭诊断帧输出。私有工作集通过 Windows QueryWorkingSet 统计驻留的进程私有页；同时记录私有提交和总工作集。

## 结果

| 测量阶段 | 私有工作集 | 私有提交 | 总工作集 |
| --- | ---: | ---: | ---: |
| 优化前预览版，两轮后收起 | 26.934 MiB | 37.117 MiB | 75.852 MiB |
| 优化后预览版，两轮后收起 | 11.859 MiB | 20.914 MiB | 47.410 MiB |
| 优化后预览版，三轮后收起 | 12.305 MiB | 21.258 MiB | 47.848 MiB |
| 优化后正式版，两轮后收起 | 12.695 MiB | 21.723 MiB | 50.230 MiB |

相同两轮操作的预览对比中，私有工作集约减少 56%，私有提交约减少 44%。正式实例冷启动收起时私有工作集为 6.070 MiB；加载图标和字体后约为 12.7 MiB，因此冷启动值不代表日常使用状态。

工作区大小为 2560×1392。收起时透明窗口的绘制缓冲区约为 340×341 像素、0.442 MiB；展开后会随面板边界增大，收起时释放较大的软件渲染目标。图标按可见内容加载，避免为不可见面板项目提前保留全部 Shell 图标。

## 如何理解这些数字

这是单台电脑上的短时对照测量，不代表所有设备都能得到相同结果，也不是长期内存泄漏测试。私有工作集是当前驻留的进程私有物理页；总工作集还包含 Windows 共享页面，不能把它们视为同一个指标。操作系统版本、图标关联、Shell 扩展、屏幕尺寸和桌面软件都会影响测量值。
