# 当前能力与限制

## 已提供

- 2–8 个可配置分类，支持应用、文件、文件夹、网页快捷方式。
- 圆环可显示分类图标、沿弧文字或两者；可分别设置各分类的语义图标。
- 面板支持排序、移除收藏、滚动、拖入文件和快捷方式。
- 收藏列表和圆环位置保存在 exe 同目录的 `config.json`。
- 设置可选择 Windows 原图标或低饱和处理后的原图标。
- 圆环用青色进度环显示整机 CPU 使用率，用紫色进度环显示整机物理内存使用率；内圈小圆点随本地时间平滑移动，每分钟绕行一圈。
- 天气背景会尝试读取 Windows 系统位置，显示当前天气、昼夜和简单的云雨雪、风效；启动时获取，之后每 30 分钟更新，也可在设置中手动更新。

## 当前限制

- 目前为 Windows 桌面程序，仅提供 x64 发布包。
- 界面是逐像素半透明玻璃，不是 Acrylic 或实时背景模糊。
- 当前按主显示器工作区定位；跨屏拖动与多屏 DPI 行为尚未完整验证。
- 不支持全局键盘导航；完全透明处的点击会传给桌面，不保证点击其他窗口即可收起面板。
- 文件拖放只接受 Windows 文件路径格式且允许复制的来源；不会接受纯文本或只允许移动的拖放。
- WinMemoryCleaner 是可选的外部组件，不随 Ring Dock 发布。临时文件清理不依赖它。

## 隐私与权限

- 分类、收藏路径、布局和偏好设置只写入本地 `config.json`。
- 天气功能会读取 Windows 系统位置，并将坐标发送给 Open-Meteo 查询天气；也可在设置界面手动发起定位和更新。
- 安装 WinMemoryCleaner 后，程序启动时会请求一次 UAC 权限，以启动只处理低优先级内存整理的助手；没有该组件或拒绝授权时，圆环仍可运行。
- 清理功能会在用户点击圆环中心时处理当前用户临时目录中超过 24 小时的文件；跳过正在使用的文件和重解析点。操作结果会在界面显示。
